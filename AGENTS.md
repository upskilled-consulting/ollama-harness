# AGENTS.md — ollama-harness

Developer and agent reference for the `harness-refactor` codebase.

---

## What this is

`oh` is a self-improving agentic research harness that runs local LLMs via Ollama (or vLLM). It wraps a multi-stage pipeline — planner → search → synthesis → wiggum evaluation loop — and exposes 30+ composable slash-command skills. The dashboard (`dashboard/`) provides a React/Vite UI for run inspection, analytics, and RLHF feedback.

## Running

```bash
# REPL
oh

# Single task
oh research attention mechanisms in transformers, save to ~/Desktop/out.md

# With skills and flags
oh --no-wiggum /cite /deep research RAG pipeline design

# API server
oh --serve
# or
harness
```

## Wiggum evaluation

6 dimensions → weighted composite (pass ≥ 9.0 to halt loop, max 3 rounds):

| Dimension | Weight |
|-----------|--------|
| depth | **0.25** |
| relevance | 0.20 |
| completeness | 0.20 |
| grounded | 0.15 |
| specificity | 0.10 |
| structure | 0.10 |

`depth` is the dominant dimension. A bullet list of one-liners scores ≤ 5. See `harness/skills/wiki/evaluation.md` for full rubric anchors.

## Adding wiki pages for /introspect

Any `.md` file in `harness/skills/wiki/` with `introspect: true` in its YAML frontmatter will be loaded by `/introspect` and `/contextualize`. Format:

```markdown
---
title: My Page
introspect: true
---

# My Page

...content...
```

Files `index.md` and `log.md` are skipped.

## Key environment variables

| Variable | Effect |
|----------|--------|
| `HARNESS_PRODUCER_MODEL` | Default LLM for synthesis |
| `HARNESS_EVALUATOR_MODEL` | Default LLM for wiggum evaluation |
| `OLLAMA_KEEP_ALIVE` | Model keep-alive in seconds (`-1` = always on) |
| `WIGGUM_PANEL` | Set `1` to enable 3-persona panel |
| `HARNESS_HEADED` | Set `1` to show browser window |
| `HARNESS_KEEP_BROWSER` | Set `1` to leave browser open |
| `CLAUDE_WEBHOOK_URL` | POST run summary on completion |
| `HARNESS_HOURLY_RATE` | Human hourly rate for leverage calculation (default: 75.0) |

## Dashboard

```bash
cd dashboard && npm run dev    # Vite dev server → http://localhost:5173
cd dashboard && npm run build  # Production build to dashboard/dist/
```

The FastAPI server serves `dashboard/dist/` at `/` in production.

Key views: **Runs** (Pipeline DAG + Context Window treemap), **Analytics**, **Artifacts**, **Sessions**, **Submit**.
